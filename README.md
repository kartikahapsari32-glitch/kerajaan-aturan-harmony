"# kerajaan-aturan-harmony" 

Buka `KERAJAAN-ATURAN-HARMONY.html` di browser. Presentasi ditampilkan sebagai SPA
layar penuh dengan ukuran slide yang menyesuaikan layar dan hanya menyediakan
tombol tutup di area khusus agar tidak menutupi tombol asli pada slide. Musik latar
dicoba untuk diputar otomatis dan berulang. Browser dapat mewajibkan interaksi
pertama pada halaman sebelum mengizinkan audio atau layar penuh."

Gambar PNG tiap slide disimpan terpisah di folder `slides/` dan dimuat saat
dibutuhkan. Simpan folder tersebut bersama HTML, `spa.js`, `spa.css`, dan file
MP3 agar gambar, tautan, dan audio tetap berfungsi. Gambar menggunakan elemen
`<img>` (bukan `<embed>`) agar tautan tombol yang sudah tertanam pada slide tetap
berada di posisi yang benar."
